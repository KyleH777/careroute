## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet client -> API | Untrusted body/query/headers; the published viewer account (ADR-0009) makes anonymous reads possible |
| API -> Log Analytics (stderr JSON) | Anything logged leaves the DB's access controls and is kept 90 days |
| API -> Postgres | Audit rows share the route's transaction |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-07 | Spoofing | actor on record_access rows | mitigate | Actor is only user.email from require_role (ADR-0004); no schema has an actor field; test_actor_cannot_be_spoofed covers body, query and header |
| T-06-08 | Repudiation | PHI leaves without an audit row | mitigate | stage() in the same session before commit, response built after commit, exceptions not caught -> 500; test_fail_closed_read, test_fail_closed_write_rolls_back, test_fail_closed_on_real_permission_error |
| T-06-09 | Information disclosure | audit log lines | mitigate | emit() logs only action, actor, request_id, integer ID lists and provider IDs; test_audit_lines_carry_no_phi scans for sentinel name/MRN/DOB/reason/note |
| T-06-10 | Denial of service | worklist limit driving huge inserts and oversized log lines | mitigate | limit: Query(20, ge=1, le=100) -> 422 outside range; test_worklist_limit_bounds |
| T-06-11 | Repudiation | a new PHI route added without auditing | mitigate | test_every_route_is_audited_or_exempt fails CI; test_behaviour_table_covers_every_audited_route forces a behavioural test too |
| T-06-12 | Tampering | forged X-Request-ID stored in rows | accept | request_id_var already validated by ^[A-Za-z0-9._-]{8,64}$ or replaced by a uuid (Phase 4); column is String(64) |
| T-06-13 | Denial of service | public viewer account filling record_access | accept | Bounded per request by the limit cap; login rate limiting (ADR-0013); manual prune in runbook (plan 03); 0.5 GB/day Log Analytics cap |
