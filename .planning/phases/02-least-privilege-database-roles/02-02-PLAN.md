<objective>
Roll the role split out to Azure in three reversible stages, then prove criteria 1-3 with in-VNet checks.

Stage A (additive, nothing live changes): new passwords, secrets, identities and the bootstrap job; image bumped to one containing db_roles.py. Run bootstrap.
Stage B (switch): `database-url` becomes the app role; migrate uses `database-url-migrate`; jobs move to their own identities with per-secret access.
Stage C (tighten): remove the API identity's vault-wide Secrets User.
</objective>
